# 课程笔记完整性检查清单

## 资料层

- [ ] 所有用户提供的文件、文件夹和记录均已登记。
- [ ] 每份资料都有类型、范围、可读性和解析状态。
- [ ] 无法打开、缺页、扫描模糊、乱码或公式识别失败项已单独列出。

## 知识点层

- [ ] 已先建立知识点清单，再组织章节。
- [ ] 每个知识点都有稳定 ID、来源定位和覆盖状态。
- [ ] 定义、条件、边界、反例、推导步骤和教师强调未因去重被删除。
- [ ] 资料之间的冲突或差异已并列记录，未静默裁决。

## 笔记层

- [ ] 每章说明核心概念、关联知识点和来源。
- [ ] 重要公式/定理有符号、条件、推导或来源、直观意义、应用方法和限制。
- [ ] 例题按基础理解、标准应用、综合提高、拓展挑战递进。
- [ ] 每道题已区分原始题、改编题和智能体补充题。
- [ ] 易错点、知识辨析和适用边界已覆盖课程重点。
- [ ] 有教学价值的原始图片/表格/流程图已记录文件名、页码、知识点和资源路径或待处理状态。

## 真实性层

- [ ] 原始资料内容、归纳总结、智能体补充已明确区分。
- [ ] 没有把未读取内容写成已分析内容。
- [ ] 待确认项说明了具体问题和需要补充的材料。
- [ ] 补充内容没有被误标为原始资料。

## 文件与交付层

- [ ] Markdown 文件实际写入输出位置并可打开。
- [ ] 图片相对路径均存在，或明确标记为未导出/待确认。
- [ ] 来源索引可以从笔记回到原始文件位置。
- [ ] 完整性检查结果已写入交付物。
- [ ] 新增资料已优先增量更新受影响部分，未无理由重建全部内容。
