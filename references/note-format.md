# 课程笔记格式

## 推荐主结构

```text
# 课程名称
## 0. 资料范围与阅读状态
## 1. 课程总览
## 2. 知识索引
## 3. 第 1 章……
### 3.1 核心概念
### 3.2 公式与定理
### 3.3 例题（按难度递进）
### 3.4 易错点与辨析
### 3.5 原始配图与图示说明
## 4. 重要公式与定理手册
## 5. 综合复习与题型索引
## 6. 来源与图片索引
## 7. 完整性核验记录
## 8. 待确认与无法读取项
```

按课程实际需要增删章节，但不要删除有知识价值的部分来追求短小。

## 来源标签

使用以下标签并附来源定位：

- `[原始资料：文件名，页码/章节]`
- `[归纳总结：基于 K-xx、K-yy]`
- `[智能体补充：补充目的与依据]`
- `[待确认：问题、所需材料]`

每个关键断言、公式、图表结论和例题答案都应能追溯到来源或明确标注为归纳/补充。

## 公式条目

每个重要公式至少包含：公式本体、符号表、适用条件、推导或来源、直观解释、使用步骤、一个应用例子、限制或常见误用。若推导来自资料，保留关键中间步骤。

## 原始图片条目

```markdown
### 图 P-01：图片标题或用途
- 原文件：`lecture-03.pdf`
- 位置：第 12 页 / 图 3
- 对应知识点：`K-07`
- 教学价值：说明变量关系/流程/实验装置……
- 文件引用：`images/lecture-03-p12.png`（若文件实际存在）
- 状态：已保留 / 仅记录来源 / 待导出 / 无法确认
```

图片不得只作为装饰；需要说明它帮助理解什么。
